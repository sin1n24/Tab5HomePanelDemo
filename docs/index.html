M5Stack Tab5（5インチのタッチ画面）に、家電のお手入れと消耗品の予定を期日の近い順に並べます。 終わったら「やった」、開けたら「開封」、買ったら「届いた」をタップするだけ。 消耗品は開封した間隔から、次に買う日を見積もります。

本番版は Wi-Fi で自宅PCの台帳とつながり、記録すると AI アシスタント（xangi）が Discord へのお知らせの予約を入れ直します。 このデモ版はTab5 本体だけで動きます。データは架空で、記録は保存されません（電源を切ると元に戻ります）。

必要なもの

  • M5Stack Tab5
  • USB-C ケーブル（データ通信できるもの。充電専用は不可）
  • パソコンの Google Chrome または Microsoft Edge（スマホ・Safari・Firefox は非対応）

① 書き込む

Tab5 をパソコンに USB でつないで、下のボタンを押してください。チップの版（初期ロット v1.x／新しい v3.x）を読み取って、合う方のファームウェアを自動で書き込みます。

このブラウザは Web Serial に対応していません。パソコンの Chrome または Edge で開いてください。

くわしいログ

ボタンを押すとポートの選択画面が出ます。Tab5 のポート（「USB JTAG/serial debug unit」など）を選んで「接続」を押してください。 書き込みには 1〜2 分かかります。終わったら自動で再起動します（画面が変わらなければリセットボタンを1回押してください）。

⚠️ 書き込むと、Tab5 に入っているプログラムは上書きされます。書き込みと利用は自己責任でお願いします。

② 使い方

やった　お手入れを今日やったことにする（次の期日が先に延びる）
開封　消耗品を開けた（在庫 −1、開封日からペースを計算し直す）
届いた　買った消耗品が届いた（数を選んで在庫 +）
+1日／+7日　日付を進める。期日を迎えた品は「お知らせ」が出る
最初から　デモのデータを最初の状態に戻す
？ 説明　しくみの説明とこのページの QR コード
期限切れ今日 3日以内まだ先

何もしないで3分たつと画面が暗くなります。暗いときの最初のタッチは、明るくするだけです。

❓ うまくいかないとき

  • ポートが出てこない／接続できない：Arduino IDE・PlatformIO・M5Burner・ほかのタブなど、シリアルを使っているものを全部閉じてください。ケーブルを替える、PC に直接挿すのも効きます。
  • それでも接続できない：Tab5 のリセットボタンを長押ししてダウンロードモードにしてから、もう一度「書き込む」を押してください（手順は M5Stack 公式の Tab5 ページ）。
  • 「Tab5 ではないようです」と出る：別の機器のポートを選んでいます。Tab5 のポートを選び直してください。
  • ボタンが押せない：スマホや非対応のブラウザです。パソコンの Chrome／Edge で開いてください。
